MESSAGE

遅いことは、
欠点ではありません。

1989年、神田の文具店の二階で、私たちは三人で会社を始めました。当時からずっと、コードは鉛筆で書いています。

ニュースで情報漏えいが報じられるたびに、私たちは同じことを考えます。その一行は、誰かが本当に考えて書いたものだったのか。
手で書けば、考えずに書くことはできません。
読めない字は書き直しを求められ、曖昧な処理は赤ペンで囲まれます。

当社の開発は、一般的な開発の数倍の時間がかかります。
その時間のすべてが、お客様の情報を守るために使われています。

代表取締役　墨田 正筆
PRINCIPLES

行動指針

  1. 一、写すな、書け。他人のコードを写すときも、自分の頭を通してから書く。
  2. 一、消しゴムは二度まで。三度消したくなった行は、設計から見直す。
  3. 一、読めない字は、脆弱性である。入力課が読み違える字は、いずれ誰かが読み違える。
  4. 一、原本は金庫へ、写しは心へ。書き終えた原稿はその日のうちに金庫へ納める。
  5. 一、急ぐ案件ほど、楷書で。崩し字は、急いだ証拠として残る。
ホーム／サービス
SERVICE

サービス

すべてのサービスは、鉛筆・赤ペン・原稿用紙の三点で提供しています。料金はいずれも税抜、原稿用紙代を含みます。

01

手書き受託開発

業務システム、Webシステム、窓口予約、在庫管理など。要件の聞き取りから納品まで、すべての工程を手で行います。外部ライブラリは使用せず、必要な処理はすべて当社で書き起こします。

料金　1行 ¥1,800〜（査読・清書込み）期間目安　12か月〜
02

既存システムの書き起こし

打鍵で作られた既存のソースコードを印刷し、全行を手で書き写します。書き写す過程で見つかった不要な処理や危うい箇所は、赤ペンで記録したうえで修正します。保守をお引き受けする前提となるサービスです。

料金　1行 ¥900〜期間目安　1万行あたり約6か月
03

赤ペンセキュリティ監査

御社のソースコードを印刷し、3名の赤ペン査読員が順に読みます。指摘は朱で書き込み、監査報告書とともに添削済みの印刷物一式をお返しします。

料金　1,000行あたり ¥120,000〜納品物　添削済み印刷物・手書き報告書
04

写経研修

当社が選定した安全なコードを、受講者が原稿用紙に一字ずつ写します。新人研修、セキュリティ研修、インシデント後の再発防止研修としてご利用いただいています。

料金　1名1日 ¥38,000（鉛筆・原稿用紙込み）定員　1回12名まで
ホーム／開発工程
PROCESS

開発工程

ご依頼から納品まで、八つの工程を経ます。いずれの工程も省略はいたしません。

01

聞き取り

対面にてご要望を伺います。議事録は二枚複写の伝票に記入し、一枚をその場でお渡しします。

02

設計

5mm方眼紙に、画面と処理の流れを鉛筆で描きます。定規の使用は認めています。

03

下書き

2Bの鉛筆で、筆記堂式コード用原稿用紙に一行ずつ書きます。コピー＆ペーストは物理的に不可能です。

04

赤ペン査読

3名の査読員が順に読み、朱で指摘を入れます。読みにくい字も指摘の対象です。

05

清書

指摘を反映し、HBの鉛筆で清書します。消しゴムの使用は一行につき二回までと定めています。

06

二重打鍵

入力課の2名が別室で同じ原稿を打鍵し、結果を照合します。一致した行のみを採用します。入力端末はネットワークに接続されていません。

07

試験

試験項目も手書きです。結果は一項目ずつ合否印で記録します。

08

納品

稼働するシステムと、製本したソース原本の写し一式をお届けします。原本は当社の金庫で永年保管します。

TOOLS

使用する道具

鉛筆（2B・HB）下書きは2B、清書はHB。シャープペンシルは芯が折れた際の誤記を防ぐため使用しません。
コード用原稿用紙80桁×40行の自社製。インデントを揃えるための縦罫が4桁ごとに入っています。
赤ペン（朱）査読専用。査読員以外の社員が持ち歩くことは禁止しています。
日付印・綴じ紐版の管理に使います。綴じ紐の色で、開発中・査読中・確定を区別します。

ホーム／セキュリティへの取り組み
SECURITY

セキュリティへの取り組み

情報漏えいの多くは、ネットワークの向こう側から起きます。当社のソースコードは、紙の上にあります。

工程 03–05原稿用紙（原本）
→
三重施錠耐火金庫
→
ネットワーク非接続入力課（二重打鍵）
→
納品お客様の実行環境

原本とネットワークが接する地点は、ありません。

原本の物理保管

原稿は書き終えたその日のうちに耐火金庫へ納めます。三つの鍵は代表・総務部長・査読主任が別々に保管しています。

ネットワーク非接続の入力端末

入力課の端末は外部と一切つながっていません。USB端子は樹脂で封止しています。

外部ライブラリ不使用

必要な処理はすべて当社で書き起こします。依存関係に由来する脆弱性は、構造上発生しません。

生成AI不使用

学習データに由来するコードが混入する余地はありません。全行の書き手を特定できます。

筆跡登録制度

全社員の筆跡を登録しています。原稿に第三者の筆跡が混じった場合、査読工程で検知します。

書き損じの廃棄

書き損じた原稿用紙はクロスカット裁断のうえ、溶解処理します。処理の際は二名が立ち会います。
